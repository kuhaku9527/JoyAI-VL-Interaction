## D-2026-07-11-046  KWS bt 唤醒词（sherpa-onnx，进程内无端口）

- **事实**: 唤醒词检测用 **sherpa-onnx** 引擎加载 **bt** 唤醒词模型（CPU / ONNX 推理），**进程内运行、无独立端口**——由 webinfer/webui 进程内调用，不走网络。模型由 `kws-training` 自训产出（CTC + Zipformer2 → ONNX）。
- **来源**: ADR-0002（2026-07-11）+ git `d75faf6`
- **对话证据**: 会话记录/基于我的项目背景和资料生成完整架构方案…json（07-21 00:36/00:55/01:04/01:54）：「KWS sherpa-onnx（56MB 编码器，FAR 2%/recall 49%）」「本地 ASR/KWS sherpa-onnx（进程内，已有）」「sherpa-onnx v4」—— 印证 KWS=sherpa-onnx 进程内、版本 v4
- **校验**: `grep -n "sherpa\|KWS\|bt\|CTC\|Zipformer2" services/kws-training/train_kws.py` → :1 "KWS 自训入口：CTC + Zipformer2"；:10 导出 ONNX 到 `sherpa-onnx/models/kws/bt-en/`；运行时加载 bt-en ONNX（进程内）
- **预期**: 训练产出 bt-en sherpa-onnx ONNX；运行时进程内无端口
- **Drift**: 无（注：train_kws.py 内数据路径 `<workspace>/data/kws/...` 是训练期外溢路径，非运行时，隔离纪律问题仅限训练脚本，不影响服务）
- **Owner**: ML / 后端
