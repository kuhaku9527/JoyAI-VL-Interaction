## D-2026-07-26-006  gh CLI 推送路径（绕沙箱 + gh-proxy + fine-grained PAT）

- **事实**: 本机 `gh` 已登录 github.com（kuhaku9527，repo scope）。推送/开 PR **必须**：
  1. `dangerouslyDisableSandbox:true` 才真联网（沙箱默认拦截 git/gh 网络）；
  2. push 走 `gh-proxy` insteadOf（直连 `https://github.com` 的 git 协议被 Connection reset）；
  3. 开 PR 须清 `local + global` 两层 `insteadOf`（键名小写 `insteadof`），否则 `gh` 静默改写 remote 报"none of the git remotes point to a known GitHub host"；
  4. 推 **workflow 文件须 fine-grained PAT**（`gho_` OAuth 推 workflow 被拒）。
- **来源**: 主理人实测（2026-07-26~28 验证）；`MEMORY.md` 工程规范段
- **校验**: `git config --get-regexp insteadof` 查看当前 insteadOf 键（应小写）；`gh auth status` 应 show 已登录；推 workflow 测试若被拒即缺 fine-grained PAT
- **预期**: insteadOf 键为小写 `insteadof` 且 local+global 两层一致；gh 已登录；workflow 推送用 PAT
- **Drift**: 无（曾因 insteadOf 键名大写 `insteadOf` 导致 gh 报错的坑已记录在案）
- **Owner**: DevOps
- **锁定**: 🔒

## D-2026-08-03-003  agent 自检须 ruff check + ruff format --check 双跑（PR #72 实证）

- **事实**: CI `quality.yml` 的 ruff 门禁含 **formatter**（`ruff format --check services/webinfer`），非仅 linter（`ruff check`）。agent 实现 / reviewer 门禁若只跑 `ruff check` 会漏掉 formatter 门禁——PR #72 首跑即因 `infer_loop.py`/`prompt_assembly.py` 格式不符挂 `ruff` job，补 `ruff format` 重提交才过。
- **来源**: 2026-08-03 实测（PR #72 run 30810769891）；D-2026-07-22-008 已记 format --check 事实，本条补**操作约束 + 实证**
- **校验**: agent 自检命令须含 `ruff format --check .`（或对应子目录）+ `ruff check .`；`grep "ruff format --check" .github/workflows/quality.yml` 应命中
- **预期**: 本地 `ruff format --check` 全绿才推 PR；避免 PR 首跑栽 formatter
- **Drift**: 无
- **Owner**: DevOps / 架构
- **锁定**: 🔒
