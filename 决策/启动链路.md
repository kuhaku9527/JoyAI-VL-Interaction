- **预期**: 启动走 run-windows.ps1，无独立逻辑。
- **Drift**: 无。
- **Owner**: DevOps 端。
- **锁定**: 🔒

- **Owner**: DevOps 端 / ML 端。
- **锁定**: 🔒（决策值不变；漂移待修）

## D-2026-07-28-008  ✅ 已闭环：run-windows.env 已含 memory-store 8997 覆盖行
- **事实**: 2026-07-28 自验时 `run-windows.env` 无 `MEMORY_PORT`/`JOYAI_MEMORY_STORE_URL` 覆盖行，须手动 env 才能起 8997 真后端；**2026-08-04 重新核 `services/scripts/run-windows.env` 真实内容，已含 `MEMORY_PORT=8997` / `MEMORY_STORE_URL=http://127.0.0.1:8997` / `JOYAI_MEMORY_STORE_URL=http://127.0.0.1:8997` / `JOYAI_ENABLE_MEMORY_STORE=1`**。故 minimal 模式现可自动带起 8997（D-L1-001 实测 7060/8070/8099/8997 全 up），不再依赖手动 env。
- **来源**: 2026-08-04 主理人核 `run-windows.env` 真实内容（含上述 4 行）+ `D-L1-001` 实测；原 2026-07-28 自验见下方 Drift。
- **校验**: `Select-String -Path services/scripts/run-windows.env -Pattern "MEMORY_PORT=8997|JOYAI_MEMORY_STORE_URL"` 应**命中**（非零）。
- **预期**: 命中，即脚本自带 8997 覆盖，minimal 无需手动 env。
- **Drift**: 🟢 **已闭环（2026-08-04）**：早期"须手动 env"的漂移因 `run-windows.env` 后续补了 8997 覆盖行而消除；`Start-Webui` 经 `run-windows.env` 注入 `JOYAI_MEMORY_STORE_URL` 后 webui 网关打 8997，不再 502。（另注：`D-L1-003` 的 "minimal=main+webinfer+webui" 定义已被 `D-L1-001` 的 2026-08-04 实测"minimal 含 memory-store"取代，待统一更新该 🔒 条目。）
- **修复(待 #43)**: 原拟在 `run-windows.env` 加 8997 覆盖行 —— **已完成**（见 事实），无需再改脚本。
- **Owner**: DevOps 端。
- **锁定**: 🔒（漂移已闭环）

## D-2026-08-04-001  ⚡ 操作铁律：最小栈启动命令 + 前置 checklist（防 AI 反复忘启动）
- **事实**: 拉起最小端到端栈用 **`start-joyai.ps1 -Mode minimal`**（minimal=main+webinfer+webui+memory-store；2026-08-04 实测 ~1 分钟内四服务全 up：7060/8070/8099/8997）。**venv 在 `D:\AI\envs\joyai-main\python.exe`（根目录，不是 Scripts/python.exe）** —— 这是 AI 多次误判"venv 坏/启动失败"的根因：根目录 python.exe 完好即算可用，别去验 `Scripts/python.exe`。
- **来源**: 2026-08-04 主理人按 `doc/service-startup.md` 实测跑通（minimal 起 7060/8070/8099/8997 全 health ok）；`doc/service-startup.md` §2/§4；`run-windows.ps1:64,96` + `run-windows.env` 覆盖 venv（D-L1-004）。
- **校验（启动前置 checklist，缺一不可）**:
  1. `Test-Path D:\AI\envs\joyai-main\python.exe` → **True（看根目录，别看 Scripts/）**
  2. `Test-Path D:\AI\workspace\JoyAI-VL-Interaction-main\services\scripts\run-windows.env` → True（本地 untracked 覆盖配置，git 不保护、易丢；丢失则回退 `.example` 模板）
  3. `Test-Path D:\AI\bin\llama.cpp\llama-server.exe` → True
  4. GGUF：`Test-Path D:\AI\models\main\JoyAI-VL-Interaction-Preview-IQ4_NL-GGUF\joyai-vl-interaction-preview-iq4_nl-imat.gguf` → True
  5. 端口空闲：7060/8070/8099/8997 不被占（被占是"跑不起来"高频原因）
- **预期**: `& start-joyai.ps1 -Mode minimal` 后（**须后台/独立窗口拉起；前台工具调用一结束进程树被回收，服务留不住**），`Invoke-RestMethod http://127.0.0.1:8070/health` 与 `:8997/health` 均 ok；停服务用 `start-joyai.ps1 -Stop`。
- **Drift**: 与 D-L1-008 表面矛盾已澄清——2026-08-04 核 `run-windows.env` 真实内容确认已含 `MEMORY_PORT=8997` 等覆盖行，故 minimal 自动带起 8997（非 8996 空壳），与实测一致；**D-L1-008 已闭环**。
- **Owner**: DevOps 端 / 前端。
- **锁定**: 🔒
